# LoadFinder v4

## Added
- unified multi-exchange search pipeline
- GPS location endpoint
- Trans.eu OAuth connection boundary
- audit table for exchange actions
- Android backend models for GPS/offers/acceptance

## Safety/business rules
- Auto Search may run automatically.
- Auto Bid is opt-in.
- Auto Accept remains off by default.
- Contractual actions require explicit confirmation in this build.
- Real exchange operations require approved provider API scopes.
