# LoadFinder cloud development connection

The repository is connected to the LoadFinder GitHub workspace used for this project.

## Phone-only workflow

1. Open the repository on GitHub.
2. Open **Actions**.
3. Choose **LoadFinder Android Build**.
4. Tap **Run workflow**.
5. Open the workflow run and inspect the build/test output.
6. When successful, download the `loadfinder-debug-apk` artifact.

## Important

The authoritative project source is the repository branch containing the verified LoadFinder source. Do not upload partial files on top of it. Future changes should be made from the latest verified project state and re-checked end-to-end.
